# 研途萤火 🦟

为 2026 考研人设计的个人助理。

## 快速开始

试试这些问题(任选一个):

- `CCNU 复试分数线多少?`
- `云南农大 招生人数`
- `哪些学校避数学?`
- `北京大学 信息公开`

## 主要功能

- 🔍 **本地资料检索**:你已摄入的 PDF / 调研报告
- 🌐 **研招网实时查询**:院校库、专业库、招生简章
- 🎯 **择校建议**:基于你的画像(分数/偏好/地区)智能推荐

## 个性化

点右上角 **⚙️ 设置**(或在下方点 ⚙️ 设置按钮)调整你的画像(分数、偏好、地区、时间轴),保存后所有对话立即生效。
